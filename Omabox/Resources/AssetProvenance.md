# Omabox artwork

The original Flare resources and Icon Composer artwork are copied byte for byte from Aayush Pokharel’s Flare project. Omabox retains the original resource names so the shared settings illustrations and glass design components use the same artwork.

Flare’s desktop thumbnail is identified in its source as an Unsplash photograph. Its provider marks come from LobeHub’s static SVG collection and include the CoreSVG path normalization already present in Flare. Provider marks are retained with the original asset collection and do not imply that Omabox integrates with those services.

The source Flare repository has no standalone license file and identifies its app copyright as © 2026 Aayush Pokharel, all rights reserved. Reuse here was requested by the owner for Omabox.

`OmarchyMark.png` is the unmodified `icon.png` from the official [Omarchy source](https://github.com/omacom/omarchy/blob/346e69e1cec6c4e8924531874af6ba010a1bc99e/icon.png), pinned to commit `346e69e1cec6c4e8924531874af6ba010a1bc99e`.

`OmarchyPreview.png` is an unmodified 1440 × 900 screenshot captured from Omabox’s native Apple Virtualization guest during the three-boot verification run. It shows the bundled Omarchy 4.0.2 desktop at 1× scale with the upstream Quattro wallpaper and first-run notifications. The screenshot was captured with `grim` from a disposable QA installation, and contains no personal account information. It represents the software-rendered desktop shipped in the app. Guest source and artwork provenance are recorded in [the guest documentation](../../Guest/README.md).

The home page’s split layout is based on the installed Helm app’s welcome window. No Helm account data or application code is included.
