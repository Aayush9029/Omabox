# Omabox artwork

The original design resources and Icon Composer artwork were created for Aayush Pokharel’s applications and reused in Omabox at his request. The shared settings illustrations and glass design components retain the original artwork.

The desktop thumbnail is identified in the original source as an Unsplash photograph. The provider marks come from LobeHub’s static SVG collection and include the existing CoreSVG path normalization. Provider marks are retained with the original asset collection and do not imply that Omabox integrates with those services.

The original design source has no standalone license file and identifies its copyright as © 2026 Aayush Pokharel, all rights reserved. Reuse here was requested by the owner for Omabox. The artwork is not covered by this repository’s MIT license; third-party photographs and marks retain their original terms.

`OmarchyMark.png` is the unmodified `icon.png` from the official [Omarchy source](https://github.com/omacom/omarchy/blob/346e69e1cec6c4e8924531874af6ba010a1bc99e/icon.png), pinned to commit `346e69e1cec6c4e8924531874af6ba010a1bc99e`.

The home page’s split layout is based on the installed Helm app’s welcome window. No Helm account data or application code is included.
